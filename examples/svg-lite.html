Note: The Lite version loads each SVG icon individually using CSS background-image: url(), rather than using a combined SVG Sprite Sheet.

For example, the Ableton icon is called in the CSS as:

.lh_ableton {
        background-image: url("https://l.habyby.net/images/social/svg/ableton-logo-transparent.svg");
    }
Only the individual SVG icons used on your page are loaded.
